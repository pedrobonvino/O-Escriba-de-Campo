# o-escriba-de-campo

Este é o meu projeto de captura diária dentro do meu Universo de Memória. 

Ele serve para registrar o que chega rápido no dia a dia e depois reler com calma, organizar melhor e transformar em nota, sala, vínculo ou memória. 

Aqui eu junto: 
- textos curtos; 
- imagens;
- áudios;
- conteúdos da web; 
- casos-limite e dúvidas de classificação. 
  
A ideia não é só guardar informação. É capturar o vivo, sem perder minha voz, minha estética e meu jeito de pensar.

 ## O que tem aqui 
 
 - `INSTRUCOES.md`: regras de funcionamento da skill. 
 - `CASOS-LIMITE.md`: exemplos de ambiguidade e desempate.
 - `REFERENCIAS/`: salas, emoções e estética do `.md`. 
 - `EXEMPLOS/`: modelos práticos por modalidade.
   
 # Como usar 
   
   Este projeto serve como base para o Claude me ajudar a ler capturas do cotidiano com clareza, rapidez e sensibilidade. 
   
 A prioridade é: 
 1. capturar bem; 
 2. classificar com precisão; 
 3. preservar minha voz; 
 4. manter a beleza da nota; 
 5. deixar tudo reaproveitável depois. 
 
 ## Princípio central 
 
 Captura rápida primeiro. Interpretação depois.
