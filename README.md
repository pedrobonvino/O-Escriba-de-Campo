# O-Escriba-de-Campo
Projeto de captura diária do Universo da Memória. Aqui eu junto textos, imagens, áudios e conteúdos da web para registrar o cotidiano, organizar o que chega rápido e transformar depois em nota, sala, vínculo ou memória, sem perder minha voz, minha estética e meu jeito de pensar.
