# Roda das Emoções — referência aplicada

Esta referência reúne o aparato de Plutchik e o Feeling Wheel da Gloria Willcox, adaptados pro Per Ankh. Não é teoria pra mostrar erudição. É vocabulário pra nomear com mais precisão o que Pedro está sentindo quando captura.

A skill consulta este arquivo quando precisa decidir uma tag emocional, identificar uma combinação diádica, ou ampliar o vocabulário de uma elaboração atmosférica.

## Por que duas rodas

**Plutchik** é teórica, simbólica, com mapa rico de combinações e escala de intensidade. Casa com a estética da casa (esoterismo, mitologia, polaridades). É a espinha. Usar no modo Scriptorium e em casos onde nomear a combinação importa (awe, remorso, desespero).

**Feeling Wheel (Willcox)** é prática, com 6 centros simples e nuances ao redor. Mais fácil de usar quando Pedro está cansado e Plutchik fica pesado. É o vocabulário cotidiano. Usar no modo Cheia.

As duas se complementam. Não competem.

## As 8 primárias de Plutchik com escala de intensidade

A intensidade vai do leve ao intenso. Saber distinguir entre apreensão, medo e terror muda como a nota é escrita.

| Primária | Leve | Média | Intensa |
|---|---|---|---|
| alegria | serenidade | alegria | êxtase |
| confiança | aceitação | confiança | admiração |
| medo | apreensão | medo | terror |
| surpresa | distração | surpresa | assombro |
| tristeza | melancolia | tristeza | luto |
| aversão | tédio | aversão | repulsa |
| raiva | irritação | raiva | fúria |
| antecipação | interesse | antecipação | vigilância |

**Como usar nas tags:** `emocao/melancolia` (não `emocao/tristeza-leve`). Sempre a palavra precisa.

## Polaridades opostas (Plutchik)

- alegria ↔ tristeza
- confiança ↔ aversão
- medo ↔ raiva
- surpresa ↔ antecipação

Útil pra perceber paradoxos: Pedro registra serenidade e melancolia ao mesmo tempo? São polos. A nota pode marcar as duas: `tags: [emocao/serenidade, emocao/melancolia]`.

## Combinações diádicas

Quando duas primárias misturam, nasce uma terceira. Estas são as mais úteis pra captura:

| Combinação | Primárias | Sala provável |
|---|---|---|
| amor | alegria + confiança | Pomar (pessoa) ou Hator (geral) |
| awe / admiração | medo + surpresa | Hator (beleza) ou Alexandria (ideia) |
| otimismo | antecipação + alegria | Hator ou Vozes |
| esperança | antecipação + confiança | Maat ou Alexandria |
| culpa | alegria + medo | Maat ou Pomar |
| delight / encanto | alegria + surpresa | Hator |
| curiosidade | confiança + surpresa | Alexandria |
| sentimentalismo | confiança + tristeza | Pomar |
| submissão | confiança + medo | Maat ou Afetos |
| desespero | medo + tristeza | Afetos ou Anubis |
| vergonha | medo + aversão | Maat ou Pira |
| desapontamento | surpresa + tristeza | Afetos |
| descrença | surpresa + aversão | Maat |
| ultraje | surpresa + raiva | Pira |
| ansiedade | antecipação + medo | Afetos |
| agressão | raiva + antecipação | Pira |
| dominância | raiva + confiança | Pira |
| orgulho | raiva + alegria | Maat ou Toth |
| desprezo | aversão + raiva | Pira |
| inveja | tristeza + raiva | Maat |
| pessimismo | tristeza + antecipação | Anubis |
| cinismo | aversão + antecipação | Alexandria |
| remorso | tristeza + aversão | Maat ou Anubis |
| morbidez | aversão + alegria | Pira ou Margem |

**Como usar:** quando a captura tem peso emocional ambíguo, pensar em qual diádica nomeia melhor. *Awe* é diferente de *delight* — uma carrega medo, a outra carrega surpresa. A sala muda conforme.

## Feeling Wheel (Willcox) — 6 centros

Para o modo Cheia, quando Pedro só precisa de uma palavra simples e direta.

| Centro | Nuances cotidianas |
|---|---|
| **mad** (raiva) | irritado, frustrado, com ciúme, hostil, ressentido |
| **sad** (tristeza) | solitário, deprimido, magoado, culpado, envergonhado |
| **scared** (medo) | rejeitado, confuso, ansioso, inseguro, sobrecarregado |
| **joyful** (alegria) | excitado, criativo, esperançoso, otimista, sensual |
| **powerful** (poderoso) | confiante, valoroso, respeitado, importante, fiel |
| **peaceful** (paz) | relaxado, contente, intuitivo, sereno, amoroso |

**Como usar:** no modo Cheia, se Pedro mandou algo curto, escolher uma nuance simples da Willcox em vez de buscar a diádica precisa de Plutchik. Tempo importa mais que precisão.

## Mapeamento emoção → sala (quick reference)

Lista rápida pra heurística de sala. Não é regra fixa, é orientação inicial.

| Emoção / família | Sala provável |

| beleza, awe, encanto, deslumbramento | Galeria de Hator |
| amor, saudade, sentimentalismo, ternura | Pomar de Osíris |

| raiva ativa, ruptura, ultraje, fúria | Pira de Kali |

| análise de obra alheia | Mesa de Ganesha |

## Princípios

1. **Não rotular emoção como positiva ou negativa.** Todas pedem espaço. Tristeza é nutriente; alegria também.
2. **Não suprimir.** A roda nomeia, não substitui. "Sentir x em vez de y" não é o gesto desta skill.
3. **Vocabulário ampliado regula.** Saber nomear a diferença entre melancolia e luto já é começar a habitar a emoção.
4. **Emoções podem ser simultâneas.** Pedro pode registrar serenidade e melancolia ao mesmo tempo. Duas tags, ok.
5. **Sem mood tracker.** Sem checagem rotineira. Sem pedir nota de 1 a 10. A roda é vocabulário, não termômetro.
6. **Usar parcimônia.** Não abrir o léxico todo em toda captura. O vinho fica no tonel; abre quando ajuda a nomear, não pra exibir.

## Quando consultar este arquivo

- Decidir uma tag emocional precisa.
- Identificar uma combinação diádica que faz a captura ganhar sentido.
- Ampliar o vocabulário da elaboração atmosférica sem inventar voz.
- Calibrar a sala quando o tom emocional é a pista principal.

## Quando não consultar

- Quando a captura não tem peso emocional (só uma observação seca, um print, uma frase ouvida sem afeto).
- Quando Pedro só está conversando, sem pedir registro.
- Quando a sala já é óbvia pela pista de verbo ou sujeito.
